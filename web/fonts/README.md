# Fonts

The "La Pagina Barbara" title uses **TAN - SPRING** (the display face listed in `components/0.ai`).
Put the font file here with one of these exact names:

- `TAN-SPRING.woff2` (preferred for the web)
- `TAN-SPRING.otf`
- `TAN-SPRING.ttf`

Until a file is present the title falls back to Georgia.
